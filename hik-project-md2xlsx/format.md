# 立项报告 XLSX 版式（md→xlsx 侧）

对标样例：`前盖具身智能上下料技术预研.xlsx`。

| 项 | 约定 |
| --- | --- |
| 结构 | Sheet1，A/B 两列 |
| 字体 | 微软雅黑 11；A 加粗居中；部分栏目 B 可加粗（技术升级/当前能力/研究目标等） |
| 边框 | A 四边细线；B 右/上/下细线 |
| 列宽 | A=16.725，B=141.35 |
| 行高 | 按正文估算换行；上限 400（低于 Excel 409 上限） |
| 表格 | MD GFM → 编号列表，禁止单元格内残留 `\|` 表 |
| 合并 | 「建议与下一步计划」A 跨两行：B 上行摘要、下行细则 |
| 特殊 A 换行 | `安全与容错机制`、`导入硬门槛与 ROI`、`节拍基线与灵活启停` 等可两行显示 |

与内容 skill（如 hik_report）分工：本 skill 只负责 **版式导出**，不改写论证口径。
