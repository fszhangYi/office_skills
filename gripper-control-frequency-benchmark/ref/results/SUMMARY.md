# 参考实测摘要（Z-EFG-C65）

条件：COM3，Modbus RTU 115200，驱动 `zefg_c65.py`。明细见同目录 CSV。

| 测试 | 关键结果 |
| --- | --- |
| 同步控制频率 | 回路 31.26 Hz；-3 dB 跟踪 7.43 Hz |
| 异步控制频率 | 只写 62.53 Hz；扫频指令约 38 Hz；-3 dB 4.43 Hz（sample 25 Hz） |
| 采集频率 | 状态帧 62.52 Hz（16.0 ms）；1/2 寄存器同量级 |
| 最快开合 | 最快往复 1.615 s（开 0.832 + 合 0.784）；平均往复约 1.622 s |

这些数字仅作方法验证样本，换机/换电缆/换电源后必须重测。
