# 立项报告 XLSX 版式（xlsx→md 侧）

对标样例：`前盖具身智能上下料技术预研.xlsx` / `… v2.xlsx`。

| 项 | 约定 |
| --- | --- |
| 结构 | Sheet1，A/B 两列 |
| A | 栏目名，加粗居中，细边框，可含换行（如 `安全与\n容错机制`） |
| B | 正文，微软雅黑 11，垂直居中+自动换行 |
| 列宽 | A≈16.7，B≈141 |
| 合并 | 「建议与下一步计划」常合并 A 两行：上行摘要，下行条目 |
| 日期 | Excel 日期序列 → md 写 `YYYY-MM-DD` |

还原目标：便于再编辑的 `##` 结构，而不是像素级复刻单元格样式。
